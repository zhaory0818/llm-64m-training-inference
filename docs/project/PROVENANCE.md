# 来源与实际工作范围

上游：[jingyaogong/minimind](https://github.com/jingyaogong/minimind)，代码基线`f659b55761b754d306bd140573493a6543cafd7f`，Apache-2.0。保留许可证和原作者署名。上游说明、配图与致谢见[固定版本原文档](https://github.com/jingyaogong/minimind/blob/f659b55761b754d306bd140573493a6543cafd7f/README.md)。公开版中的改动文件带有文件内标记，具体清单见仓库根目录 SOURCE_STATE.json。

## 上游提供

- Dense/MoE模型、Tokenizer与聊天模板。
- 预训练/SFT/LoRA/DPO/蒸馏/在线RL/Agent核心实现。
- 转换、API、工具和网页示例。
- 训练数据与公开模型的获取入口。

不能把这些核心架构与训练算法说成独立原创实现；学习代码并从随机初始化训练自己的参数，与从头独立编写框架是不同工作。

## 本实践开展的工作

- 阅读并添加学习注释；完成独立环境、数据、云端/本机配置与真实训练操作。
- 保存配置、日志、SwanLab记录、权重和续训状态；核验加载、冻结/更新、LoRA合并和导出一致性。
- 针对6GB本机约束进行资源试跑、短程在线RL与CPU奖励评分适配，并记录其与默认长训练的差别。
- 完成原生/导出/API/SSE/工具/WebUI体验，增加有界运行与事件记录的辅助入口。
- 构造小型基础诊断、严格评分与助手审阅，开展标签/截断审计、长度/提示控制及作者参照；保留失败和结论边界。
- 本次整理增加可迁移Dense推理/API入口`tools/project_demo.py`、资产/结果/复现说明和干净源码交付副本。
- 增加动态右侧补齐整理器与SFT可选开关；验证监督、损失、梯度及真实更新，在同负载中测量有效吞吐。
- 定位缓存单token解码的手写注意力路径，增加带回退的SDPA实现、末位置投影设置与CLI/API统一开关；完成数值、算子、生成、协议及性能对照。
- 建立预先登记、预热同步、随机/交替顺序、配对统计、独立确认负载和原资产SHA校验的效率实验程序。

这些程序与文档由学习者在助手协作下逐步完成，不等于所有代码均由学习者独立手写。面试应能讲清实际操作和关键路径，尚未独立掌握的部分不作过度表述。

## 改动审计

最初83文件收尾快照中的原核心文件改动以学习注释/排版为主，AST审计对应当时版本。其后效率改进增加了真实计算路径和数据整理代码，并在`trainer/train_full_sft.py`与`tools/project_demo.py`可选接入；默认保持原流程。**当前v2不能继续统称所有改动均为注释或AST不变。** 原`model/model_minimind.py`、Dataset和Tokenizer未改写；新增路径有独立正确性与回退验证。详见效率报告和v2源码清单。生成的本地WebUI副本另包含长度限制、日志和工具边界适配。

原始训练和诊断日志在本机，轻量发布副本只携带选择过的曲线/CSV和诊断开发集证据；不携带账号凭证、SSH私钥、完整云端会话或环境目录。模型、数据与外部奖励模型来源分别登记，不把下载资产算为自己训练成果。
